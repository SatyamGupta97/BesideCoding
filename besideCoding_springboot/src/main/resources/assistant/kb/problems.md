# Problems and submissions

## Browsing problems

- Open **Problems** (`/problems`) to see the problem set.
- Use the category filter, the topic and company filters, and the search box to narrow the list.
- Each row shows the title, difficulty and topic tags.

## Opening a problem

The problem page has two tabs on the left:

- **Description**: the statement, difficulty, topics, companies and like/dislike buttons.
- **Solution**: the written solution, when one exists.

The right panel is where you answer.

## Submitting an answer

- **Multiple-choice problems**: select one of the options and press **Submit**.
- **Integer / written problems**: type your answer in the text box and press **Submit**.
- The result is either `solved` or `unsolved`; a solved marker appears next to the title.
- You must be signed in to submit.

## Solutions and hints

- The Solution tab is only for reading; the site does not run or grade code.
- Solutions stay hidden while the problem is part of a contest that is currently running. They
  become available again after the contest ends.
- The Ask Beside assistant follows exactly the same rule: no hints or solutions for a problem
  during a live contest.

## Likes

Use the like and dislike buttons under the description to rate a problem.
