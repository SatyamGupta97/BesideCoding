# Contributing problems

## Submitting a problem

1. Open **Contribute** (`/contribute`).
2. Fill in the title and the full problem description.
3. Choose the problem type:
   - **Integer**: the answer is a value the solver types in.
   - **MCQ**: provide the options and mark which one is correct.
4. Add the correct answer, a written solution, the category, sub-category, difficulty and
   (optionally) the companies that ask this problem.
5. Press submit.

## Review process

- Every contribution is stored with the status **Need_Approval**.
- A contributed problem is not visible in the public problem list until an administrator approves
  it.
- Administrators review contributions in the admin area and can approve, hold, ask for edits or
  reject them.

## What admins can manage

- **Dashboard**: user, problem, contest and submission totals, plus difficulty breakdown.
- **Users**: the list of registered users.
- **Problems**: filter, review and maintain the problem bank.
- **Contest**: create contests and add existing or new problems to them.
- **Reports**: problems flagged for review.
