# Ask Beside assistant

## What it is

**Ask Beside** is the assistant built into the site. Open it with the **Ask Beside** button in the
bottom-right corner of any page while you are signed in.

It can help with two kinds of questions:

- **How the website works** - editing your profile, changing your avatar, submitting an answer,
  joining a contest, contributing a problem, creating a discussion.
- **The problem you have open** - understanding the statement, the expected shape of the answer,
  and progressive hints about the approach.

## Contest lock

While a problem belongs to a contest that is running, the assistant is deliberately limited:

- It still answers questions about using the website.
- It refuses hints, approaches, algorithms, complexity targets, edge cases or answers for that
  problem, even if you phrase the question indirectly.
- The rule is enforced by the server for every user. Opening the problem from the practice page
  does not bypass it.
- Hints become available again when the contest ends.

## What it cannot do

- It does not run your code and cannot see your submissions or your editor contents.
- It only knows the problem statement and the site help pages, so it may be out of date about a
  brand new feature.
- It is not a search engine and cannot browse the internet.
- Answers can be wrong; treat them as guidance and verify with the solution page.
- There is a per-user hourly message limit to keep the service available.
